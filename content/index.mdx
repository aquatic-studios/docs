# Aquatic Studios Documentation

Official source of truth for every plugin, library and API maintained by **Aquatic Studios**.
Versioned alongside the source code — what you read here is what runs on your server.

If a feature is not documented here, treat it as unofficial and subject to change without notice.

## What we ship

- **Plugins** — drop-in `.jar` files for Bukkit, Spigot and Paper. Bukkit `1.16+`, Java `17+`,
  Folia-ready schedulers and no NMS.
- **Libraries** — reusable Java dependencies published on JitPack.
- **API** — public events and services you can build on top of.

Every behaviour is a key in a YAML file. Templates, messages, cooldowns and Discord payloads are
editable without touching a single line of Java.
