<FeatureGrid>
  <Feature title="Built for modern servers" emoji="🌊">
    Bukkit 1.16 → latest, Java 17+, Folia-ready schedulers and Paper-first APIs. No NMS, no version
    lock-in, no surprises after an update.
  </Feature>
  <Feature title="Configuration first" emoji="⚙️">
    Every behaviour is a key in a YAML file. Templates, messages, cooldowns and Discord payloads are
    editable without touching a single line of Java.
  </Feature>
  <Feature title="Documented API" emoji="🧩">
    Public events, services and a stable façade published on JitPack so you can build on top of our
    plugins instead of around them.
  </Feature>
  <Feature title="Actually maintained" emoji="🛠️">
    One author, one codebase, one changelog. Bugs get fixed, breaking changes get announced, and this
    site is updated in the same commit.
  </Feature>
</FeatureGrid>
