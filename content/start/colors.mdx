# Colors

Every plugin accepts these formats, in any message field:

- MiniMessage
- `<#rrggbb>`
- `&#rrggbb`
- `&x&r&r&g&g&b&b`
- `§x§r§r§g§g§b§b`
- Legacy `&` codes

```yaml
message: "<gradient:#38ecff:#0a84ff>Aquatic</gradient> &#38ecffStudios &7— &bready"
```

JSON is not supported.
