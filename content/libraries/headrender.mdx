# HeadRender

Renders a player's skin head into chat as HEX-colored pixels. Async and cached.

**GitHub:** [senkex/HeadRender](https://github.com/senkex/HeadRender)

| | |
| --- | --- |
| **MC** | `1.16+` |
| **Java** | `17+` |
| **Platform** | Bukkit / Spigot / Paper |
| **Author** | Senkex — Aquatic Studios |

## Installation

```kotlin filename="build.gradle.kts"
repositories {
    maven("https://jitpack.io")
}

dependencies {
    implementation("com.github.senkex:HeadRender:VERSION")
}
```

Replace `VERSION` with the latest release on [JitPack](https://jitpack.io/#senkex/HeadRender).
