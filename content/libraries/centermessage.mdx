# CenterMessage

Centers chat messages so they line up in the middle of the chat box.

**GitHub:** [senkex/CenterMessage](https://github.com/senkex/CenterMessage)

| | |
| --- | --- |
| **MC** | `1.8+` |
| **Java** | `17+` |
| **Platform** | Bukkit / Spigot / Paper |
| **Author** | Senkex — Aquatic Studios |

## Installation

```kotlin filename="build.gradle.kts"
repositories {
    maven("https://jitpack.io")
}

dependencies {
    implementation("com.github.senkex:CenterMessage:VERSION")
}
```

Replace `VERSION` with the latest release on [JitPack](https://jitpack.io/#senkex/CenterMessage).
