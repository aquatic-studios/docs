# AquaCrates

<p>
  <Badge variant="danger">Experimental</Badge> <Badge variant="neutral">Unreleased</Badge>
</p>

Crates, keys and animated reward reveals, built on top of AquaCore so every message, sound and
webhook uses the templates you already wrote.

<Callout type="warning">
  This plugin is still in development. Nothing on this page is final — command names, config keys and
  the API surface can all change before release.
</Callout>

## Planned scope

- Physical and virtual crates, with per-crate key items.
- Weighted reward tables with guaranteed-drop counters.
- Three reveal animations: roulette, cascade and instant.
- Preview GUI showing every reward and its real chance.
- Full AquaCore integration for broadcasts and Discord webhooks.
- `CrateService` published through [AquaAPI](/api/aquaapi).
