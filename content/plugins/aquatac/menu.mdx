# Board

Everything visual lives in `menu.yml`.

## Titles

```yaml filename="menu.yml"
board:
  titles:
    turn: "&#54ADF4%player%&8's turn"
    win: "&#8DFF87%player% won!"
    draw: "&#FFA42D Draw!"
    forfeit: "&#8DFF87%player% won!"
```

The GUI title changes with the state of the match. `%player%` is whoever the title is about: the
player to move, or the winner.

## Markers

```yaml filename="menu.yml"
  markers:
    first:
      material: BLUE_DYE
      display_name: "&#54ADF4● First player"
    second:
      material: WHITE_DYE
      display_name: "&#F0F8FF○ Second player"
    empty:
      enabled: true
      material: GRAY_STAINED_GLASS_PANE
      display_name: "&8Empty cell"
```

| Key | What it does |
| --- | --- |
| `first` | Item for the player who moves first |
| `second` | Item for the other one |
| `empty` | Filler in a free cell. `enabled: false` leaves it blank |

Any material of your server version works.

## Sounds

```yaml filename="menu.yml"
sounds:
  move: "BLOCK_NOTE_BLOCK_HAT:1:1"
  win: "ENTITY_PLAYER_LEVELUP:1:1"
  lose: "ENTITY_VILLAGER_NO:1:1"
  draw: "BLOCK_NOTE_BLOCK_BASS:1:1"
```

The format is `SOUND:volume:pitch`. `win` plays for the winner, `lose` for the other player.
