# AquaTac

Two players play tic tac toe on a chest board. They can bet on it, practise against a bot, and every
result is kept as stats.

| | |
| --- | --- |
| **Commands** | `/tictactoe` to play, `/aquatac` to administer |
| **Minecraft** | `1.16+` |
| **Folia** | Supported |
| **Storage** | SQLite or H2 |
| **Soft-depend** | Vault, PlaceholderAPI |

## A match

1. A player runs `/ttt invite <player> [bet]`, or just `/ttt <player>`.
2. The other accepts. Both stakes are taken.
3. The board opens as a chest GUI. Players click a cell on their turn.
4. The winner takes the pot, minus the tax if you set one. A draw refunds both.

Against the bot it is one command: `/ttt bot [difficulty]`. Bot matches are always free.

## Economy

Vault is no longer required. Three backends:

| Type | Moves money with |
| --- | --- |
| `CUSTOM` | Your own commands, so any economy plugin works |
| `VAULT` | Vault plus an economy plugin |
| `NONE` | Nothing. Every match is free |

If the chosen backend cannot start, the plugin falls back to `NONE` and matches stay playable for
free instead of breaking.

<Callout type="warning">
  The permission root changed in `1.1.0`. `tictactoe.play` is now **`aquatac.play`**. Update your
  permission plugin or nobody will be able to challenge.
</Callout>

## Files

| --- | --- |

| `menu.yml` | Board titles, markers and sounds |
