# AquaClan

Clans with four ranks, invitations that survive restarts, homes, a shared bank, mail, alliances and
rivalries, a leveling curve with rewards, custom banners, Discord notices and 36 editable menus.

**Soft-depend:** PlaceholderAPI, Vault, ItemsAdder, Oraxen, Nexo

## Ranks

| Rank | Can |
| --- | --- |
| `LEADER` | Everything, including disband and transfer |
| `CO_LEADER` | Manage members, homes and relations |
| `MODERATOR` | Whatever the leader grants it |
| `MEMBER` | Use the clan, chat, bank and homes |

What each rank can do is not fixed. `/clan role set` toggles individual permissions per rank, so a
`MODERATOR` can be anything from a glorified member to almost a co leader.

`/clan promote` and `/clan demote` move a player between them. `/clan transfer` hands leadership
over.

## Points and levels

Points come from combat and raise the clan level. Each level can grant extra homes, member slots and
allies, and those benefits stack.

```yaml filename="config.yml"
points:
  per-kill: 10
  per-death: 0
  rival-kill-bonus: 5
  ally-kill-penalty: 15
```

Killing a rival is worth more. Killing an ally **costs** points.

## Files

| File | Holds |
| --- | --- |
| `config.yml` | Names, limits, economy, invites, chat input |
| `level.yml` | The curve and the reward per level |
| `webhook.yml` | Discord notices for 15 clan events |
| `messages.yml` | Every string |
| `menus/*.yml` | 36 menus, one file each |

`config.yml`, `messages.yml`, `level.yml` and `webhook.yml` update themselves when a release adds
options, without touching your changes.

<Callout type="info">
  Almost everything is reachable from a menu. `/clan` opens the main one and `/clan short` a quick
  four button version.
</Callout>
